# Quantum Harmonic Oscillator
This repo is part of a personal journey learning Lean.

The goal is to prove the [quantum harmonic oscillator](https://en.wikipedia.org/wiki/Quantum_harmonic_oscillator) has a discrete spectrum of energy using the algebraic properties of the ladder operators, $`a`$ and $`a^\dagger`$, and the number operator $`N = a^\dagger a`$.

## Contents
- Definition and properties of commutators
- Definition and properties of the number operator
- Norm-related properties
- Existence of a ground state
- Discreteness of the number operator eigenvalues
