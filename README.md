# Quantum Harmonic Oscillator
This repo is part of a personal journey learning Lean.

Here the goal is to prove the [quantum harmonic oscillator](https://en.wikipedia.org/wiki/Quantum_harmonic_oscillator) has a discrete spectrum of energy based on the algebraic properties of the ladder operators, $`a`$ and $`a^\dagger`$, and the number operator $`N = a^\dagger a`$.
